# fahmiwol's Claude plugin marketplace

```
/plugin marketplace add fahmiwol/claude-plugins
```

| Plugin | What it does |
|---|---|
| **[ship-check](plugins/ship-check)** | Verify a deploy actually landed and the page actually renders. Three read-only tools, two skills, one command. |
| **[agent-craft](plugins/agent-craft)** | Four methods for building agent systems that hold up: small-model backbone design, an eight-gate change loop, borrowing a desk GPU from a CPU server, and repo handoff. |

```
/plugin install ship-check@fahmiwol
/plugin install agent-craft@fahmiwol
```

Everything here is MIT licensed and runs locally. No account, no API key, no telemetry.
